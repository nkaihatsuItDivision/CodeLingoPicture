📊 Apache POI の基本概念と階層構造
1
📁
Workbook
XSSFWorkbook
📁 ワークブック（Excelファイル全体）
Excel ファイル全体を表すトップレベルのオブジェクト。
複数のシートを含み、ファイルの保存・読み込みを管理。
Workbook workbook = new XSSFWorkbook();
// .xlsx 形式のExcelファイルを作成
2
📋
Sheet
XSSFSheet
📋 シート（ワークシート）
Workbook 内の個別のシート。「学生一覧」「検索結果」など
目的別にデータを整理する単位。
Sheet sheet = workbook.createSheet("学生一覧");
// "学生一覧" という名前のシートを作成
3
📏
Row
XSSFRow
📏 行（水平方向のデータ列）
Sheet 内の横一列のデータ。1つの学生の情報や
ヘッダー行など、関連するデータの集合。
Row headerRow = sheet.createRow(0);
// 0行目（最初の行）を作成
4
🔢
Cell
XSSFCell
🔢 セル（個別のデータ項目）
最小単位のデータ格納場所。学生名、メールアドレスなど
個別の値を格納し、スタイルも設定可能。
Cell cell = headerRow.createCell(0);
cell.setCellValue("学生ID");
// セルに値とスタイルを設定
