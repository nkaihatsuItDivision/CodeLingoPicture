プロシージャで処理を分割する

❌ 分割なし（長い1つの処理）
Sub Main()
    ' 初期化処理...
    ' (10行のコード)
    
    ' データ処理...
    ' (30行のコード)
    
    ' 出力処理...
    ' (15行のコード)
    
    ' 全部で55行...
End Sub
😵 長くて読みにくい
🐛 バグを見つけにくい
🔄 再利用できない
✅ プロシージャで分割
Sub Main()
    Call Initialize     ' 初期化
    Call ProcessData   ' 処理
    Call OutputResult  ' 出力
End Sub

Private Sub Initialize()
    ' 初期化処理
End Sub

Private Sub ProcessData()
    ' データ処理
End Sub
📖 処理の流れが明確
🔍 問題箇所を特定しやすい
♻️ 再利用できる
