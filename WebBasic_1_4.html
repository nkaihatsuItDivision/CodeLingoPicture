📊 レストラン と Web の対応表
🍽️ レストランでの注文
お客さん → あなたのブラウザ
ウェイター → インターネット
キッチン → Webサーバー
料理 → Webページ
🌐 行動の対応
「注文します」 → リクエスト
「料理をお持ちしました」 → レスポンス
料理を食べる → ページを閲覧
メニューを見る → リンクをクリック
1
「ハンバーガーセットください」 ≒ 「このページを表示して」
2
ウェイターがキッチンに伝達 ≒ ブラウザがサーバーに要求
3
キッチンで料理を準備 ≒ サーバーでページを準備
4
料理をお客さんに提供 ≒ ページをブラウザに送信
