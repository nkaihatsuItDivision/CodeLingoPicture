🔗 GETでのURLパラメータ表示

GETリクエストではパラメータがURLに直接表示されます

https://www.google.com/search?q=開発者ツール&hl=ja&safe=active&source=hp
🔍 URLの構造解析
https://www.google.com/search?q=開発者ツール&hl=ja&safe=active&source=hp
部分 役割 説明
https://www.google.com/search ベースURL アクセス先のサーバーとページのパス
? パラメータ開始 ここからGETパラメータが始まることを示す
q=開発者ツール 検索キーワード Googleの検索クエリパラメータ
& パラメータ区切り 複数パラメータを区切る文字
hl=ja 言語設定 表示言語を日本語に指定
safe=active セーフサーチ 安全な検索結果のみ表示
✅ GETリクエストの特徴
URLにすべての情報が表示される
GETリクエストでは、送信するデータがすべてURL内に含まれます。そのため、アドレスバーを見るだけで何が送信されているかが分かります。
📍 アドレスバーでの確認
https://example.com/search?keyword=JavaScript&category=programming&sort=date

確認ポイント：

  • パラメータが丸見えで表示される
  • URLをコピーして共有可能
  • ブックマークに保存される
🌐 Networkタブでの確認
Name Status Type
search?keyword=JavaScript&category=programming&sort=date 200 document

確認ポイント：

  • Name列にもパラメータが表示
  • Headers画面で詳細確認可能
  • リクエストの詳細情報を分析
📝 実際のGETパラメータ例
🔍 Google検索
https://www.google.com/search?q=HTML+CSS&tbm=isch&source=hp
パラメータ解析：
• q=HTML+CSS → 検索キーワード「HTML CSS」
• tbm=isch → 画像検索モード
• source=hp → 検索開始位置（ホームページ）
🛒 ECサイトの商品検索
https://shop.example.com/products?category=electronics&price_min=10000&price_max=50000&sort=popular
パラメータ解析：
• category=electronics → カテゴリ「電子機器」
• price_min=10000&price_max=50000 → 価格帯10,000〜50,000円
• sort=popular → 人気順でソート
📊 API呼び出し
https://api.weather.com/v1/weather?city=Tokyo&units=metric&lang=ja
パラメータ解析：
• city=Tokyo → 対象都市「東京」
• units=metric → メートル法単位
• lang=ja → 日本語レスポンス
