Spring Data JPAページネーション構成

Pageable・Page・Sortを活用した効率的なデータ処理アーキテクチャ

1
Controller
リクエストパラメータからPageableオブジェクトを自動生成
@GetMapping("/students")
public String list(
  Pageable pageable,
  Model model)
2
Service Layer
PageableをRepositoryに渡してビジネスロジックを処理
public Page<Student>
findAllWithPaging(
  Pageable pageable)
3
Repository
Spring Data JPAが自動でページング機能を提供
Page<Student> findAll(
  Pageable pageable);
// 自動実装される
4
Database
LIMIT・OFFSET句を使用した効率的なクエリ実行
SELECT * FROM students
ORDER BY id
LIMIT 10 OFFSET 20

Pageable・Page・Sort詳細構成

Pageableパラメータ
  • page int
  • size int
  • sort String[]
?page=0&size=10
&sort=name,asc
&sort=age,desc
Pageオブジェクト情報
  • content List<T>
  • totalElements long
  • totalPages int
  • number int
  • size int
