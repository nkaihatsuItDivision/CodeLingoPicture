Week 9.1-9.4：フォーム処理基盤
StudentData（DTO設計）
フォーム専用DTOによるEntity分離設計。保守性とセキュリティを両立した入力データ管理。
public class StudentData {
    @NotBlank(message = "名前は必須です")
    private String name;
    
    @Email(message = "正しいメール形式で入力してください")
    private String email;
}
Thymeleaf フォーム
th:object・th:fieldによるフォームバインディング。直感的で保守性の高いUI実装。
<form th:object="${studentData}" method="post">
    <input th:field="*{name}" class="form-control">
    <div th:errors="*{name}" class="error"></div>
</form>
Bean Validation
@NotBlank・@Email・@Min/@Maxによる自動入力検証。宣言的でタイプセーフな検証システム。
@Min(value = 1, message = "学年は1以上で入力してください")
@Max(value = 4, message = "学年は4以下で入力してください")
private Integer grade;
UX改善
th:errorsによる条件分岐表示。エラー時の親切なユーザーガイダンスでUX向上。
<div th:if="${#fields.hasErrors('name')}"
     class="alert alert-danger">
    <span th:errors="*{name}"></span>
</div>
Week 9.5-9.6：CRUD操作基盤
@PostMapping（新規登録）
フォーム受け取り・バリデーション実行・DB保存の一連の処理。RESTful設計に準拠。
@PostMapping("/students")
public String registerStudent(
    @Valid @ModelAttribute StudentData studentData,
    BindingResult bindingResult) {
    // 登録処理
}
@PatchMapping（データ更新）
既存データの部分更新処理。適切なHTTPメソッドによるセマンティックな設計。
@PatchMapping("/students/{id}")
public String updateStudent(
    @PathVariable Long id,
    @Valid @ModelAttribute StudentData studentData) {
    // 更新処理
}
Repository連携
MyBatisとの連携によるデータベース操作。レイヤー分離によるクリーンアーキテクチャ。
@Autowired
private StudentRepository studentRepository;

studentRepository.save(student);
楽観ロック（並行制御）
OptimisticLockingFailureExceptionによる排他制御。マルチユーザー環境での整合性保証。
try {
    studentRepository.save(student);
} catch (OptimisticLockingFailureException e) {
    // 楽観ロックエラー処理
}
Week 9.7：フィードバック基盤
Flash属性
RedirectAttributesによる一時メッセージ管理。PRGパターンでのセッション活用技術。
redirectAttributes.addFlashAttribute(
    "successMessage", "学生を登録しました");
成功・エラー処理
操作結果に応じた適切なユーザーフィードバック。成功・失敗の明確な案内システム。
String message = String.format(
    Messages.STUDENT_REGISTERED,
    student.getName());
redirectAttributes.addFlashAttribute(
    "successMessage", message);
View統合
Thymeleaf fragmentsによる統一メッセージ表示。一貫性のあるUI・UX設計。
<div th:replace="fragments/messages :: success-message">
</div>
<div th:replace="fragments/messages :: error-message">
</div>
アーキテクチャ設計
定数クラス・MessageSourceによる拡張可能なメッセージ管理。エンタープライズ対応設計。
public class Messages {
    public static final String STUDENT_REGISTERED =
        "学生「%s」を登録しました";
}
