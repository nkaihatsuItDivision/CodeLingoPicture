MVC分離Before/After図：Controller肥大化問題の解決

❌ Before：Controller肥大化問題
@Controller
public class StudentController {
    @Autowired
    private StudentRepository repository;

    @PostMapping("/students")
    public String create(@Valid StudentData data) {
        // ❌ ビジネスロジックがControllerに混在
        if (data.getAge() < 18) {
            throw new RuntimeException("未成年");
        }
        Student student = new Student();
        student.setName(data.getName());
        repository.save(student);
        return "redirect:/students";
    }
}
⚠️ 単一責任原則違反
🔧 テスト困難性
🔄 再利用性低下
📈 保守性悪化
✅ After：Service層分離による解決
@Controller
public class StudentController {
    @Autowired
    private StudentService studentService;

    @PostMapping("/students")
    public String create(@Valid StudentData data) {
        // ✅ ビジネスロジックはServiceに委譲
        studentService.createStudent(data);
        return "redirect:/students";
    }
}

@Service
public class StudentService {
    public void createStudent(StudentData data) {
        validateAge(data.getAge());
        // ビジネスロジック処理
    }
}

🧪 テスタビリティ改善
🔄 再利用性向上
🛠️ 保守性向上
