データベース保存処理の流れ

🗃️ JPA Repository による安全な永続化
エンティティの変換からデータベース保存まで完全自動化
1
DTOからEntityへの変換
バリデーション済みのStudentDataをStudent Entityに変換
Student student = studentData.toEntity();
// Week 9.1で設計したtoEntity()メソッドを活用
2
Repository インジェクション確認
Spring Boot が自動でStudentRepositoryをインジェクション
@Autowired
private StudentRepository studentRepository;
// Week 8.6で設定したJPA Repository
3
トランザクション開始
Spring Bootが自動でトランザクション管理を実行
// @Transactionalアノテーションにより自動実行
// データ整合性を保証
4
データベース保存実行
JPAによるINSERT文の自動生成・実行
Student savedStudent = studentRepository.save(student);
// 自動でIDが設定されたエンティティが返される
5
トランザクション完了
正常終了時のコミット、エラー時の自動ロールバック
// 成功時：COMMIT実行
// 例外時：ROLLBACK実行（データ整合性維持）
🔧 StudentRepository の役割
public interface StudentRepository extends JpaRepository<Student, Long> {
    // Week 8.6で作成したRepository
    // save()メソッドが自動で提供される
    
    // save()の動作：
    // - ID未設定 → INSERT文実行
    // - ID設定済み → UPDATE文実行
}
🛡️
トランザクション管理
データ整合性を自動保証
@Transactional
public String createStudent(...) {
    // 例外発生時は自動ロールバック
    studentRepository.save(student);
}
⚠️
エラーハンドリング
DB例外の適切な処理
try {
    studentRepository.save(student);
} catch (DataAccessException e) {
    // エラー処理
    log.error("DB保存エラー", e);
}
🎯 Week 9.5 完全実装例
@PostMapping("/students")
public String createStudent(@Valid @ModelAttribute StudentData studentData,
                          BindingResult bindingResult) {
    // バリデーションエラーチェック
    if (bindingResult.hasErrors()) {
        return "students/form";
    }
    
    try {
        // DTOからEntityへ変換
        Student student = studentData.toEntity();
        
        // データベース保存
        Student savedStudent = studentRepository.save(student);
        
        // PRGパターンでリダイレクト
        return "redirect:/students";
    
    } catch (DataAccessException e) {
        // DB例外時の処理
        bindingResult.reject("database.error", "保存に失敗しました");
        return "students/form";
    }
}
