https://www.example.com:443/products/smartphones.html?color=red&size=large#features

🔗 1. プロトコル
https://
意味：「この方式で通信します」
種類：
• http:// = 普通の通信
• https:// = 安全な通信（推奨）
現在はセキュリティのためHTTPSが標準
🌐 2. ドメイン名
www.example.com
意味：「この会社のサーバー」
構成：
• www = サブドメイン
• example = 会社・サービス名
• .com = トップレベルドメイン
インターネット上の住所のようなもの
🚪 3. ポート番号
:443
意味：「サーバーの窓口番号」
標準：
• HTTP = :80（省略可）
• HTTPS = :443（省略可）
通常は表示されない（自動で設定）
📁 4. パス
/products/smartphones.html
意味：「サーバー内の場所」
構造：
• / = ルート（トップページ）
• /products/ = フォルダ
• smartphones.html = ファイル
フォルダ階層を表現（実際のファイルとは限らない）
❓ 5. クエリパラメータ
?color=red&size=large
意味：「追加の条件・情報」
構造：
• ? = パラメータ開始
• & = 複数パラメータの区切り
• color=red = 色の指定
検索条件、設定、オプションなどに使用
🎯 6. フラグメント
#features
意味：「ページ内の特定場所」
用途：
• ページ内リンク
• 目次からの直接ジャンプ
• アンカーリンク
ページが読み込まれた後に該当箇所にスクロール
🌍 実際のURLの例
Google検索の場合：
https://www.google.com/search?q=プログラミング学習
YouTubeの動画ページ：
https://www.youtube.com/watch?v=dQw4w9WgXcQ#t=30s
オンラインショップの商品ページ：
https://shop.example.jp/category/electronics/laptops?brand=apple&price_max=200000
🧩 演習：URLを分解してみよう
以下のURLを各部分に分解してみましょう：
https://search.yahoo.co.jp/search?p=Web開発&x=wrt#results
💡 答え：
• プロトコル：https://
• ドメイン名：search.yahoo.co.jp
• パス：/search
• クエリ：?p=Web開発&x=wrt
• フラグメント：#results
