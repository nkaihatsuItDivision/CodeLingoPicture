セキュリティ強化
Spring Security統合・認証認可・脆弱性対策
企業運用で必須となるセキュリティ要件を満たすため、Spring Security を統合して認証・認可・CSRF対策・SQL インジェクション対策など、包括的なセキュリティ機能を実装します。
📝 実装タスク
  • 🔐
    Spring Security設定クラス・SecurityFilterChain 作成
  • 👤
    ユーザー認証・ログイン・ログアウト機能実装
  • 🛡️
    ROLE_ADMIN・ROLE_USER によるアクセス制御実装
  • 🔒
    CSRF・XSS・SQL インジェクション対策実装
💡 実装ヒント
  • BCryptPasswordEncoder でパスワードを安全にハッシュ化
  • @PreAuthorize アノテーションでメソッドレベルのアクセス制御
  • Thymeleaf の th:csrf でCSRFトークン自動生成
  • @Valid・@Sanitized で入力値検証・サニタイズ実装
✅ 確認ポイント
  • 未認証ユーザーが管理画面にアクセスできないこと
  • ROLE_USER が管理者専用機能を使用できないこと
  • CSRFトークンなしのPOSTリクエストが拒否されること
  • SQLインジェクション攻撃を試しても正常に防御されること

デプロイ準備・Docker化
コンテナ化・環境分離・CI/CD基盤構築
開発・テスト・本番環境での一貫したデプロイを実現するため、Docker によるコンテナ化を行い、環境設定の分離とCI/CDパイプラインの基盤を構築します。
📝 実装タスク
  • 🐳
    Dockerfile・docker-compose.yml 作成
  • 🏗️
    マルチステージビルドによる最適化実装
  • 🌍
    開発・テスト・本番環境の設定ファイル分離
  • ⚙️
    GitHub Actions による基本的なCI/CDパイプライン構築
💡 実装ヒント
  • 軽量なJRE イメージ（openjdk:17-jre-slim）を使用してサイズ最適化
  • application-{env}.yml で環境別設定を分離
  • docker-compose で アプリ・MySQL・Redis の3コンテナ構成
  • .dockerignore でビルドに不要なファイルを除外
✅ 確認ポイント
  • docker-compose up でシステム全体が正常起動すること
  • コンテナ間通信でデータベース接続が正常動作すること
  • 環境変数による設定切り替えが適切に動作すること
  • イメージサイズが適切に最適化されていること（< 500MB）
