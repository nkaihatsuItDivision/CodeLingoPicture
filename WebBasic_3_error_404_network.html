❌ 404 Not Found
Request URL: https://example.com/missing-script.js
Error: The requested resource could not be found on this server.
原因: 指定されたファイルがサーバー上に存在しません。

詳細情報:

  • HTTPステータスコード: 404 (Not Found)
  • リクエストメソッド: GET
  • ファイルタイプ: JavaScript
  • 呼び出し元: index.html
🔍 404エラーの見つけ方
Network画面での特徴:
• Status列に赤色の「404」が表示される
• 該当行が赤い背景でハイライトされる
• Size列に「failed」と表示される
• エラーの行は点滅やアニメーションで強調される
🛠️ 404エラーの解決手順
  1. エラーファイルを特定
    Networkタブで赤色表示されている404エラーの行を見つけます。Name列でファイル名を確認してください。
  2. ファイルパスを確認
    エラー行をクリックして詳細を確認し、Request URLでアクセスしようとしているファイルパスが正しいかチェックします。
  3. 実際のファイル存在確認
    サーバー上やプロジェクトフォルダ内に、該当するファイルが実際に存在するかを確認してください。
  4. パスの修正
    ファイルが存在する場合は、HTMLやCSSでの参照パスを修正します。存在しない場合は、ファイルを作成するか参照を削除します。
📝
タイプミス
ファイル名のスペルミス、拡張子の間違い、大文字小文字の違いが原因
📁
パス間違い
相対パス・絶対パスの間違い、フォルダ階層の認識ミスが原因
🗑️
ファイル削除
参照されているファイルが削除されたり、移動されたことが原因
⚙️
サーバー設定
サーバーの設定問題やアクセス権限の不備が原因
