📋 POSTでのForm Data確認

POSTリクエストではデータがURLに表示されず、Form Dataとして送信されます

🔗 GET リクエスト
https://example.com/login?username=user123&password=secret123
👁️ データが丸見え

パスワードなどの機密情報がアドレスバーに表示されてしまいます

📋 POST リクエスト
https://example.com/login
🔒 データが隠されている

URLにはパラメータが表示されず、データは安全に送信されます

Request URL:
https://example.com/api/login
Request Method:
POST
Status Code:
✅ 200 OK
Content-Type:
application/x-www-form-urlencoded
📋 Form Data
フィールド名 値 説明
username user123 ユーザー名
password •••••••• パスワード（非表示）
remember_me true ログイン状態保持
csrf_token abc123def456ghi789 セキュリティトークン
💡 POSTでのForm Data確認方法
開発者ツールの使い方：
1. F12で開発者ツールを開く
2. Networkタブに移動
3. フォーム送信後、POSTリクエストをクリック
4. Headers画面下部の「Form Data」セクションで送信データを確認
🔗
GET リクエスト
データがURLに含まれるため、セキュリティ面で注意が必要
  • ❌ パスワードが丸見え
  • ❌ ブラウザ履歴に残る
  • ❌ サーバーログに記録
  • ❌ URLで共有すると危険
🔒
POST リクエスト
データが本文に含まれ、URLには表示されないため安全
  • ✅ データが隠されている
  • ✅ ブラウザ履歴に残らない
  • ✅ 大容量データも送信可能
  • ✅ セキュリティが向上
🛡️
HTTPS + POST
最も安全な組み合わせ。通信内容が暗号化される
  • ✅ 通信が暗号化される
  • ✅ 盗聴を防げる
  • ✅ データの改ざん防止
  • ✅ 企業レベルのセキュリティ
