1
📋 既存データ取得

処理概要:
IDを指定して既存の学生データを取得し、編集フォーム用のDTOに変換

GET /students/5/edit

使用技術:

@PathVariable Repository.findById() fromEntity()
@GetMapping("/{id}/edit")
public String showEditForm(
    @PathVariable Long id,
    Model model) {
    Student student = studentRepository
        .findById(id)
        .orElseThrow(...);
    StudentData data =
        StudentData.fromEntity(student);
    model.addAttribute("studentData", data);
    return "students/edit";
}

💾 更新処理実行

処理概要:
フォームデータを受け取り、バリデーション後にデータベースを更新

PATCH /students/5

処理フロー:

  • バリデーションチェック
  • DTO→Entity変換
  • 楽観ロック制御
  • データベース更新
  • 成功時リダイレクト

使用技術:

@PatchMapping @Valid toEntity() @Version
@PatchMapping("/{id}")
public String updateStudent(
    @PathVariable Long id,
    @Valid @ModelAttribute StudentData data,
    BindingResult result) {
    if (result.hasErrors()) {
        return "students/edit";
    }
    Student student = data.toEntity();
    student.setId(id);
    studentRepository.save(student);
    return "redirect:/students";
}
