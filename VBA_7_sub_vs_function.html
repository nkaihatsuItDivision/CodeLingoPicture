Sub と Function の違い

📤 Sub（処理のみ）
引数 → 処理 → 戻り値なし 
Sub ShowMessage(msg As String)
    MsgBox msg
End Sub

' 呼び出し
Call ShowMessage("Hello")
用途：画面表示、ファイル保存、データ更新など
🔄 Function（値を返す）
引数 → 処理 → 戻り値 
Function Add(a As Long, b As Long) As Long
    Add = a + b  ' 戻り値
End Function

' 呼び出し
result = Add(10, 20)  ' 30
用途：計算、判定、変換、データ取得など
