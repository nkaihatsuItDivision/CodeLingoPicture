public class ServiceException extends RuntimeException {
    private final String errorCode;

    public ServiceException(String message, String errorCode) {
        super(message);
        this.errorCode = errorCode;
    }
}

🟠 ValidationException
public class ValidationException extends ServiceException {
    public ValidationException(String message) {
        super(message, "VALIDATION_ERROR");
    }
}

// 使用例
if (age < 18) {
    throw new ValidationException("年齢は18歳以上である必要があります");
}

🟣 DataNotFoundException
public class DataNotFoundException extends ServiceException {
    public DataNotFoundException(String resource, Object id) {
        super(String.format("%s (ID: %s) が見つかりません",
              resource, id), "DATA_NOT_FOUND");
    }
}

// 使用例
Student student = repository.findById(id)
    .orElseThrow(() -> new DataNotFoundException("学生", id));

🎯 Service層での例外変換
@Service
public class StudentService {
    public void validateAge(int age) {
        if (age < 18) {
            throw new ValidationException(
                "年齢は18歳以上");
        }
    }
}

ビジネスルール違反を適切な例外に変換

2
🎮 Controller層でのキャッチ
@Controller
public class StudentController {
    @PostMapping("/students")
    public String create(@Valid StudentData data,
                       RedirectAttributes ra) {
        try {
            studentService.create(data);
        } catch (ServiceException e) {
            ra.addFlashAttribute("error", e.getMessage());
        }
    }
}

public class StudentController {

            studentService.create(data);

            // エラーの種類ごとに個別処理
        } catch (RuntimeException e) {
            // 汎用的すぎる例外処理
        }
    }
}

@Controller
public class StudentController {
    @PostMapping("/students")
    public String create(@Valid StudentData data,
                       RedirectAttributes ra) {
        try {
            studentService.create(data);
        } catch (ServiceException e) {
            // 統一的な例外処理
            ra.addFlashAttribute("error", e.getMessage());
        }
    }
}
  • ✅ 例外処理ロジックの統一化
  • 📝 一貫したエラーメッセージ
  • 👤 優れたユーザビリティ
