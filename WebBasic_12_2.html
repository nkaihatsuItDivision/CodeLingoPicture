カード型レイアウトの例 - padding/marginの効果
❌ padding/margin が少ない場合
padding: 5px
margin: 5px
カード1

テキストが枠に近くて読みにくい。カード同士も詰まっている。

カード2

余白が少ないため、窮屈に見える。

カード3

プロフェッショナルな印象を与えにくい。

.card { padding: 5px; /* 内側余白が少ない */ margin: 5px; /* 外側余白が少ない */ border: 1px solid #e2e8f0; background: white; }

❌ 問題点：

padding不足： テキストが枠線に近すぎて読みにくい
margin不足： カード同士が近すぎて区別しにくい

⬇️ padding と margin を増やすと...
✅ 適切な padding/margin を設定した場合
padding: 20px
margin: 15px
カード1

テキストが読みやすく、余裕のあるレイアウトで見やすい。

カード2

適切な余白により、プロフェッショナルな印象。

カード3

カード同士が適度に離れて、それぞれが独立して見える。

.card { padding: 20px; /* 内側に十分な余白 */ margin: 15px; /* カード間の適切な距離 */ border: 1px solid #e2e8f0; background: white; }

✅ 改善効果：

padding増加： コンテンツが見やすく、高級感が出る
margin増加： 各カードが独立して見え、情報が整理される

💡 余白設定のコツ

  • padding: コンテンツの重要度に応じて 15px〜30px
  • margin: カード同士の関係性に応じて 10px〜20px
  • 一貫性: 同じレベルの要素は同じ余白を使用
  • バランス: padding > margin の場合が多い
