複合条件検索の実装構造

StudentSpecifications.advancedSearch()

Week 10.1基盤の拡張として、AND/OR演算子による柔軟な条件結合を実現

public static Specification<Student> advancedSearch(
    StudentSearchCriteria criteria) {
    return (root, query, criteriaBuilder) -> {
        List<Predicate> predicates = new ArrayList<>();
        
        // 基本条件の追加...
        
        // Week 10.4の核心：条件結合
        if ("OR".equals(criteria.getSearchOperator())) {
            return criteriaBuilder.or(
                predicates.toArray(new Predicate[0]));
        } else {
            return criteriaBuilder.and(
                predicates.toArray(new Predicate[0]));
        }
    };
}

Predicateリストの動的組み合わせ

検索条件に応じて動的にPredicateを生成し、柔軟な条件組み合わせを実現

// 名前検索条件
if (StringUtils.hasText(criteria.getName())) {
    Predicate namePredicate = criteriaBuilder.like(
        criteriaBuilder.lower(root.get("name")),
        "%" + criteria.getName().toLowerCase() + "%");
    predicates.add(namePredicate);
}

// 年齢範囲検索条件
if (criteria.getMinAge() != null) {
    Predicate agePredicate = criteriaBuilder
        .greaterThanOrEqualTo(root.get("age"), criteria.getMinAge());
    predicates.add(agePredicate);
}
