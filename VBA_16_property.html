Property Get / Let / Set

Property Get
値を取得する
📤 出力
Property Get Name() As String
    Name = mName
End Property
Property Let
値を設定する
📥 入力
Property Let Name(val As String)
    mName = val
End Property
Property Set
オブジェクトを設定
📦 オブジェクト
Property Set Sheet(ws As Worksheet)
    Set mSheet = ws
End Property
💡 使い方
Dim emp As New clsEmployee
emp.Name = "田中"      ' Property Let が呼ばれる
MsgBox emp.Name         ' Property Get が呼ばれる
