基本設計と詳細設計の違い
基本設計（外部設計）
🏢 システム全体の構造
対象者：
お客様・プロジェクト管理者
内容：
• 画面設計・機能一覧
• システム構成
• 外部システム連携
• データフロー
Week 10例：
• 学生管理画面構成
• 検索・一覧・詳細画面
• エクスポート機能仕様
詳細設計（内部設計）
⚙️ 実装に必要な詳細
対象者：
プログラマー・開発者
内容：
• クラス設計・メソッド仕様
• データベース詳細設計
• API 仕様・エラー処理
• アルゴリズム・処理フロー
Week 10例：
• Entity・DTO クラス設計
• Service・Repository メソッド
• Ajax API 詳細仕様
段階的な設計アプローチ
基本設計でシステムの全体像を決め、詳細設計で実装の詳細を決めることで、
効率的で品質の高い開発が可能になります。
