Option Explicit の効果

❌ Option Explicit なし
Sub BadExample()
    Dim userName As String
    userName = "田中"
    
    ' スペルミス！
    MsgBox "こんにちは、" & userNeme
End Sub
😱 実行結果
メッセージ：「こんにちは、」

名前が表示されない！
userNeme は未宣言の別変数として扱われ、空の値になる。
エラーにならないので気づきにくい！
✅ Option Explicit あり
Option Explicit

Sub GoodExample()
    Dim userName As String
    userName = "田中"
    
    ' スペルミス！
    MsgBox "こんにちは、" & userNeme
End Sub
🎉 コンパイル時にエラー
「コンパイルエラー: 変数が定義されていません。」

userNeme が未宣言であることを教えてくれる！
実行前にミスを発見できる！
💡 結論
Option Explicit は必ず設定しましょう！
VBEのオプションで「変数の宣言を強制する」にチェックを入れると、
新しいモジュールに自動で追加されます。
