@PathVariableとデータ取得図

IDによる特定レコード取得の仕組み - Week 9.6 編集機能の第一歩

🔗 URL構造と@PathVariable

GET /students/123/edit
1
URLの{id}部分が123として認識される
2
@PathVariable Long idで値を自動受け取り
3
受け取ったIDでデータベースから特定レコードを検索

⚡ データ取得処理フロー

1
コントローラーメソッド定義
@GetMappingで編集画面用のエンドポイントを定義
@GetMapping
@PathVariable
@GetMapping("/students/{id}/edit")
public String showEditForm(@PathVariable Long id,
                           Model model) {
    // 処理実装
}
2
データベース検索
findById()メソッドで特定のStudentエンティティを取得
JPA Repository
Optional
Student student = studentRepository
    .findById(id)
    .orElseThrow(() -> new IllegalArgumentException(
        "Invalid student Id:" + id));
3
DTO変換
Week 9.1のfromEntity()メソッドでStudentDataに変換
Week 9.1技術
DTO変換
StudentData studentData =
    StudentData.fromEntity(student);
4
モデル設定
変換したデータをModelに設定して編集画面に渡す
Spring MVC
Model
model.addAttribute("studentData", studentData);
return "students/edit";

📋 @PathVariableの重要な特徴

🎯 型安全性
@PathVariable Long id
// 自動的にLong型に変換
// 変換失敗時は400エラー
🔒 RESTful設計
GET /students/{id}/edit
// リソース指向URL
// REST原則に準拠

💡 この実装による4つのメリット

1. 直感的なURL設計
/students/123/edit で編集対象が明確
2. 型安全なパラメータ処理
Spring Bootが自動的に型変換とバリデーション
3. Week 9.1技術の活用
fromEntity()メソッドによる確実なDTO変換
4. エラーハンドリング
存在しないIDに対する適切な例外処理
