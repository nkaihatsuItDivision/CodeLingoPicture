Select Case の構造

Select Case dayNumber
↓ 値をチェック
Case 1
日曜日
Case 2
月曜日
Case 3
火曜日
...
...
Case 7
土曜日
Case Else
不明
Select Case dayNumber
    Case 1
        dayName = "日曜日"
    Case 2
        dayName = "月曜日"
    Case 3 To 5        ' 範囲指定
        dayName = "平日"
    Case 6, 7          ' 複数値
        dayName = "週末"
    Case Else
        dayName = "不明"
End Select
✅ Select Case向き
  • 4つ以上の分岐
  • 1つの変数を判定
  • 値が明確
❌ If文向き
  • 2〜3個の条件
  • 複合条件（And/Or）
  • 複数の変数を判定
