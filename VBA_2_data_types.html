VBA 基本データ型一覧

📝 String よく使う
文字列を格納する型
Dim name As String
name = "山田太郎"
🔢 Long 推奨
整数を格納する型（約-21億〜+21億）
Dim age As Long
age = 25
💰 Double よく使う
小数を含む数値を格納する型
Dim price As Double
price = 1980.5
📅 Date よく使う
日付・時刻を格納する型
Dim today As Date
today = #2025/1/23#
✅ Boolean よく使う
True/False の2値を格納する型
Dim isOK As Boolean
isOK = True
⚠️ Integer 非推奨
小さな整数（-32,768〜32,767）
Dim num As Integer
※ Long を使いましょう
🎲 Variant 避ける
何でも入る万能型（処理が遅い）
Dim anything As Variant
※ 特別な理由がない限り避ける
💡 データ型選びのポイント
  • 文字 → String
  • 整数 → Long（Integerではなく）
  • 小数 → Double
  • 日付 → Date
  • Yes/No → Boolean
  • 迷ったら → 上記から選ぶ（Variantは避ける）
