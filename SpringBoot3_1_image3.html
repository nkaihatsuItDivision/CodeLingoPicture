🔄 JPQL vs ネイティブSQL比較
JPQL (推奨)
@Query("SELECT s FROM Student s WHERE s.name LIKE %:name%")
List<Student> findByNameContaining(@Param("name") String name);
✅ データベース非依存
✅ タイプセーフ
✅ エンティティ直接操作
ネイティブSQL
@Query(value = "SELECT * FROM students WHERE name LIKE CONCAT('%', :name, '%')", nativeQuery = true)
List<Student> findByNameContainingNative(@Param("name") String name);
⚠️ データベース依存
⚠️ 最適化が必要な場合のみ
1
部分一致検索パターン
文字列の部分一致検索を効率的に実装。LIKEクエリの活用パターン。
@Query("SELECT s FROM Student s WHERE s.name LIKE %:name%")
List<Student> findByNameContaining(@Param("name") String name);

@Query("SELECT s FROM Student s WHERE s.email LIKE :email%")
List<Student> findByEmailStartingWith(@Param("email") String email);
2
範囲検索パターン
数値や日付の範囲検索を実装。BETWEENクエリの効果的な活用。
@Query("SELECT s FROM Student s WHERE s.grade BETWEEN :minGrade AND :maxGrade")
List<Student> findByGradeRange(@Param("minGrade") Integer minGrade, @Param("maxGrade") Integer maxGrade);

@Query("SELECT s FROM Student s WHERE s.enrollmentDate BETWEEN :startDate AND :endDate")
List<Student> findByEnrollmentDateRange(@Param("startDate") LocalDate startDate, @Param("endDate") LocalDate endDate);
3
複合条件検索パターン
複数の条件を組み合わせた高度な検索。AND/OR論理演算子の活用。
@Query("SELECT s FROM Student s WHERE s.major = :major AND s.grade >= :minGrade AND s.status = 'ACTIVE'")
List<Student> findByMajorAndGradeAndStatus(@Param("major") String major, @Param("minGrade") Integer minGrade);

@Query("SELECT s FROM Student s WHERE (s.major = :major1 OR s.major = :major2) AND s.grade BETWEEN :minGrade AND :maxGrade")
List<Student> findByMultipleMajorsAndGradeRange(@Param("major1") String major1, @Param("major2") String major2, @Param("minGrade") Integer minGrade, @Param("maxGrade") Integer maxGrade);
4
集計・グループ化パターン
COUNT、SUM、AVG等の集計関数とGROUP BYを活用した統計クエリ。
@Query("SELECT s.major, COUNT(s) FROM Student s GROUP BY s.major")
List<Object[]> countStudentsByMajor();

@Query("SELECT s.grade, AVG(s.score) FROM Student s WHERE s.major = :major GROUP BY s.grade")
List<Object[]> getAverageScoreByGradeForMajor(@Param("major") String major);

@Query("SELECT COUNT(s) FROM Student s WHERE s.enrollmentDate >= :date")
Long countStudentsEnrolledSince(@Param("date") LocalDate date);
