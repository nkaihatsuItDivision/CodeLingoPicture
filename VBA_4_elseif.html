ElseIf による多分岐

score >= 90 ?
→ True →
評価 A
↓ False
score >= 80 ?
→ True →
評価 B
↓ False
score >= 70 ?
→ True →
評価 C
↓ False
score >= 60 ?
→ True →
評価 D
↓ False
評価 F（Else）
⚠️ 注意：条件は上から順に評価される。最初にTrueになった処理だけが実行される。 
If score >= 90 Then
    grade = "A"
ElseIf score >= 80 Then
    grade = "B"
ElseIf score >= 70 Then
    grade = "C"
ElseIf score >= 60 Then
    grade = "D"
Else
    grade = "F"
End If
