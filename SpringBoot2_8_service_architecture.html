📋 @Serviceアノテーション
@Service
public class StudentService {
    // ビジネスロジックの集約
    public void createStudent(StudentData data) {
        validateBusinessRules(data);
        processStudentCreation(data);
    }

    private void validateBusinessRules(StudentData data) {
        // 業務ルール検証
    }
}
  • 🎯 ビジネスロジック専用レイヤー
  • 🧩 Spring管理対象としてBean登録
  • 📦 業務処理の責任集約
  • 🔧 保守性とテスタビリティ向上
🔗 依存性注入（DI）
@Controller
public class StudentController {
    @Autowired
    private StudentService studentService;
    // ↑ Spring Bootが自動で注入
}

@Service
public class StudentService {
    @Autowired
    private StudentRepository repository;
    // ↑ Repository層との疎結合
}
  • 🔌 @Autowiredによる自動注入
  • 🔗 インターフェース活用で疎結合
  • ⚡ Spring管理のシングルトン
  • 🧪 テスト時のモック注入対応
